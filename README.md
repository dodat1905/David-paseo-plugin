# Expand file edits for Paseo

A Paseo plugin that opens Edit and Write tool calls automatically and shows them with Monokai colors, word wrap, line numbers and Cmd+click to open the file. See [OVERVIEW.md](OVERVIEW.md).

## Install

```bash
paseo plugin install git:dodat1905/David-paseo-plugin
```

Then set Appearance > Syntax theme to Dracula and reload the Paseo window.

## Update

```bash
paseo plugin update expand-file-edits
```
